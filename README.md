# Zhengfei Song — Personal Homepage

Responsive academic homepage centered on [Google Scholar](https://scholar.google.com/citations?user=7nsfNW4AAAAJ&hl=en).

Edit `index.html` for biography and publications; edit `stylesheet.css` for appearance. Preview with `python3 -m http.server 8000`.

Profile and four publication records were transcribed from Scholar on October 7, 2026. The 2027 year follows Scholar. Citation counts are not copied; publications do not automatically synchronize. The profile has a default avatar, so the default Scholar avatar is used until a photo is supplied. No email, position, degree, or advisor has been inferred. `CNAME` is intentionally empty until a custom domain is registered and verified.

Forked from [jonbarron/jonbarron.github.io](https://github.com/jonbarron/jonbarron.github.io), whose README permits personal use. Git history is retained. Desktop layout, typography, colors, and link styling now follow the original Jon Barron template. Only a small-screen adaptation is added.
